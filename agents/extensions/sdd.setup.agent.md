description: Generate a clean, concise README.md without repetition
---

## Goal

Scan the repository and generate a simple README.md with:
1. Project description (2-3 sentences)
2. Features (bullet list, categorized)
3. Technology Stack (table)
4. Quick Start (essential steps only)

## Rules

- No repetition of information
- Keep it simple and concise
- Only document what exists
- One section per concept (no duplication)

## Output

Generate README.md with the structure above. That's it.
