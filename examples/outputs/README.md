# Example Output

This folder contains examples of outputs generated by speckit-central agents.

## Contents

### Specifications
- `order-service-spec.md` - Complete specification for the Orders Service
- `notification-service-spec.md` - Notification Service specification

### Analysis Reports
- `orders-service-analysis.md` - Technical analysis and recommendations
- `architecture-review.md` - Architecture review findings

### Planning Documents
- `implementation-plan.md` - Detailed implementation roadmap
- `project-timeline.md` - Project schedule and milestones

### Task Breakdowns
- `orders-service-tasks.md` - Task decomposition and estimates

## How to Use

1. Review examples to understand speckit-central output formats
2. Use examples as templates for your own specifications
3. Learn best practices from example structures
4. Adapt examples to your specific needs

## Example Workflow

1. **Clarify** - Use clarify agent to understand requirements
2. **Specify** - Use specify agent to create detailed specifications
3. **Analyze** - Use analyze agent to review and identify issues
4. **Plan** - Use plan agent to create implementation plans
5. **Tasks** - Use tasks agent to break down into actionable items
6. **Implement** - Use implement agent for coding guidance
7. **Review** - Use review agent for quality assurance
